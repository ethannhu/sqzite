# B+ 树操作与算法

实现：[`src/storage/btree.zig`](../src/storage/btree.zig)，节点页格式见 [节点页格式](node.md)。`BPlusTree` 持有 Pager 指针和可空 `root_page_id`。键为 `u64`，叶子 payload 为字节切片。

## 查找

`search(key)` 在根为空时返回 `null`。从根向下遍历内部节点，按分隔键选择子页；最多访问 128 层，之后报告损坏/超深错误。叶子内用二分定位有序键。命中时返回指向 Pager 缓存页数据的借用切片，页面改写或 Pager 关闭后该切片不可继续使用。

## 插入与分裂

空树插入时分配并初始化叶子根。非空时先下降到目标叶子，按序插入键和 payload。重复键返回 `DuplicateKey`。

叶子空间不足时，算法将原记录与待插入记录纳入有序序列，在按记录数均分的基础上重建左右叶子，并维护叶子后继链。右叶子的最小键作为分隔键插入父节点。若 payload 分布无法放入单页则返回 `NoSpace`。

父内部节点有空间时插入分隔键和右子页指针；已满时合并原有分隔项与新项，拆成两个内部节点，将中间分隔键向上传播。向上传播递归处理祖先；根分裂时新建内部根并更新子节点的父页号。所有修改仅先进入 Pager 缓存并标脏，由 Pager 刷新持久化。

## 删除和重平衡

`delete(key)` 返回是否找到并删除。叶子删除会压紧剩余 payload、修正偏移并保持槽位有序；若右子树最小键改变，相应父分隔键会更新。删除最后一项后树根置空。

非根内部节点以最大槽位数的一半（170）判断占用不足。叶子节点还会依据其记录能否按当前页格式重建来判断占用，因 payload 长度可变，不能只按槽位数描述叶子容量。节点占用不足时，`rebalanceNode` 先尝试与相邻兄弟重分配；重分配无法恢复占用时再尝试合并。合并删除父节点中的分隔键，因此继续向父节点重平衡。空内部根收缩为唯一子节点；根节点不受最小占用限制。

## 兄弟页、重分配与合并

`siblingPageId(page_id, direction)` 只查询同一父节点中的前/后相邻子页。根没有兄弟；父节点不引用当前页视为损坏。它不代表全树的前驱/后继。

`redistributeSiblings(left, right)` 要求两页为同父节点、相邻且同类型。叶子先按序合并记录，再在两页均可容纳的切点中取最接近平分的位置，并将右页最小键写回父分隔项；叶子链不变。内部节点将父分隔键并入有序项，取中间分隔键提升到父节点，重建两边并修正所有子节点的父页号。

`mergeSiblings(left, right)` 将右节点内容合并到左节点并删除父分隔键。叶子按序合并并接续右叶子的后继；内部节点按左项、父分隔键、右项的顺序合并并修正子页父号。父节点为空根时根收缩到左页。右页及收缩的旧根页会清零，但页号不会回收。直接调用 merge 不递归调整祖先；删除路径通过 `rebalanceNode` 完成递归。

若非同父兄弟、顺序不相邻、类型不一致、节点损坏或空间不够，操作返回对应错误。当前 `src/storage/btree_test.zig` 包含 B+ 树行为测试。
