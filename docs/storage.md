# 页面与 B+ 树

## 存储模块职责

- `pager.zig` 定义 `Page` 和 `Pager`，负责页面缓存、分配、读写与关闭。
- `node.zig` 负责把 `Page` 解释为叶子或内部节点，并封装单页布局、Cell 访问、插入与页面重建；不执行文件 I/O。
- `btree.zig` 定义 `BPlusTree`，负责跨节点搜索、插入、分裂和分隔键向根传播；页面字段布局由 Node 接口管理。

## Page 与 Pager

- 页面固定为 4096 字节，页号从 0 开始。
- 内存中的 `Page` 包含 `id`、`dirty` 和 4096 字节的 `data`。`id`、`dirty` 只用于内存控制，不写入数据库文件。
- 页在磁盘中的起始偏移是 `id × 4096`；磁盘只保存 `data` 的原始字节。
- Pager 首次读取页面时放入缓存；文件中不足一页的尾部补零。刷新时只写 `dirty` 页面，成功后清除标记；关闭时会尝试刷新所有脏页。

## B+ 树节点页布局

多字节整数均使用小端编码。每个节点对应一个 Pager 页面，节点类型由 `data[0]` 区分。

| 偏移 | 长度 | 公共头部字段 |
| ---: | ---: | --- |
| 0 | 1 | 节点类型：`1` 叶子，`2` 内部节点 |
| 1 | 2 | 槽位数量 |
| 3 | 4 | 父页号（当前搜索不使用） |
| 7 | 1 | 保留 |

公共头部长 8 字节。叶子和内部节点的头部均为 12 字节，槽位从偏移 12 开始，每个槽位占 12 字节；槽位最大数为 340。叶子值与槽位共用页面空间，因此实际可用槽位还受值数据占用空间影响。

### 叶子节点

头部偏移 8 至 11 存放下一叶子页号。每个槽位字段如下：

| 槽位内偏移 | 长度 | 字段 |
| ---: | ---: | --- |
| 0 | 8 | 键（`u64`） |
| 8 | 2 | 值在页面中的偏移 |
| 10 | 2 | 值的字节长度 |

值作为原始字节存放在同一页中。搜索会检查值区域不与头部、槽位区域重叠，且不超出页面范围。

### 内部节点

头部偏移 8 至 11 存放第一个子页号。每个槽位字段如下：

| 槽位内偏移 | 长度 | 字段 |
| ---: | ---: | --- |
| 0 | 8 | 分隔键（`u64`） |
| 8 | 4 | 分隔键右侧的子页号 |

分隔键表示右子树的下界。小于第一个分隔键的键走第一个子页；大于等于某个分隔键时，选择该分隔键对应的右子页。

`LeafNode.init` 和 `InternalNode.init` 会清零整页、初始化节点类型和头部字段，并将页面标记为脏页。`readCell` 只读取已计数的槽位；`writeCell` 可覆写已有槽位或追加下一个槽位，不允许越界或跳号写入。叶子槽位只存值数据的偏移与长度，不负责复制值内容。

## 当前 search 行为

1. 根页号为空时返回 `null`。
2. 从根页开始读取节点；内部节点用分隔键二分选择子页，最多访问 128 个节点页。
3. 叶子槽位按键升序排列；搜索用二分查找定位键。找到时返回指向 Pager 缓存页面数据的切片；未找到返回 `null`。
4. 返回切片借用缓存页面，Pager 关闭或页面数据被改写后不再有效。
5. 节点类型无效、槽位数量超出上限、值区域越界或深度超限时返回节点错误；Pager 读取失败时返回存储错误。

## 当前 insert 行为

1. 空树首次插入时，Pager 分配一个新页面并初始化为叶子根页。
2. 非空树按内部节点分隔键定位叶子，在叶子中按键升序插入槽位和值。
3. 重复键返回 `DuplicateKey`。叶子页没有足够空间时会尝试按记录数均分到左右叶子，并将分隔键插入父节点。父节点已满时会合并分隔键和子页指针后拆成两个内部节点，再将提升的分隔键递归插入上层；根节点已满时会创建新的内部根节点。若均分后值数据仍放不下，则返回 `NoSpace`。
4. 成功插入会将页面标记为脏页，由 Pager 刷新到磁盘。根页号目前由调用方持有，尚未写入数据库元数据。

删除和节点合并尚未实现。
