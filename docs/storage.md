# 页面与 B+ 树

## 存储模块职责

- `pager.zig` 定义 `Page` 和 `Pager`，负责页面缓存、分配、读写与关闭。
- `node.zig` 负责把 `Page` 解释为叶子或内部节点，并封装单页布局、Cell 访问、插入与页面重建；不执行文件 I/O。
- `btree.zig` 定义 `BPlusTree`，负责跨节点搜索、插入、分裂和分隔键向根传播；页面字段布局由 Node 接口管理。

## Page 与 Pager

- 页面固定为 4096 字节，页号从 0 开始。
- 内存中的 `Page` 包含 `id`、`dirty` 和 4096 字节的 `data`。`id`、`dirty` 只用于内存控制，不写入数据库文件。
- 页在磁盘中的起始偏移是 `id × 4096`；磁盘只保存 `data` 的原始字节。
- Pager 首次读取页面时放入缓存；文件中不足一页的尾部补零。刷新时只写 `dirty` 页面，成功后清除标记；关闭时会尝试刷新所有脏页。

## B+ 树节点页布局

多字节整数均使用小端编码。每个节点对应一个 Pager 页面，节点类型由 `data[0]` 区分。

| 偏移 | 长度 | 公共头部字段 |
| ---: | ---: | --- |
| 0 | 1 | 节点类型：`1` 叶子，`2` 内部节点 |
| 1 | 2 | 槽位数量 |
| 3 | 4 | 父页号（当前搜索不使用） |
| 7 | 1 | 保留 |

公共头部长 8 字节。叶子和内部节点的头部均为 12 字节，槽位从偏移 12 开始，每个槽位占 12 字节；槽位最大数为 340。叶子值与槽位共用页面空间，因此实际可用槽位还受值数据占用空间影响。

### 叶子节点

头部偏移 8 至 11 存放下一叶子页号。每个槽位字段如下：

| 槽位内偏移 | 长度 | 字段 |
| ---: | ---: | --- |
| 0 | 8 | 键（`u64`） |
| 8 | 2 | 值在页面中的偏移 |
| 10 | 2 | 值的字节长度 |

值作为原始字节存放在同一页中。搜索会检查值区域不与头部、槽位区域重叠，且不超出页面范围。

### 内部节点

头部偏移 8 至 11 存放第一个子页号。每个槽位字段如下：

| 槽位内偏移 | 长度 | 字段 |
| ---: | ---: | --- |
| 0 | 8 | 分隔键（`u64`） |
| 8 | 4 | 分隔键右侧的子页号 |

分隔键表示右子树的下界。小于第一个分隔键的键走第一个子页；大于等于某个分隔键时，选择该分隔键对应的右子页。

`LeafNode.init` 和 `InternalNode.init` 会清零整页、初始化节点类型和头部字段，并将页面标记为脏页。`readCell` 只读取已计数的槽位；`writeCell` 可覆写已有槽位或追加下一个槽位，不允许越界或跳号写入。叶子槽位只存值数据的偏移与长度，不负责复制值内容。

## 当前 search 行为

1. 根页号为空时返回 `null`。
2. 从根页开始读取节点；内部节点用分隔键二分选择子页，最多访问 128 个节点页。
3. 叶子槽位按键升序排列；搜索用二分查找定位键。找到时返回指向 Pager 缓存页面数据的切片；未找到返回 `null`。
4. 返回切片借用缓存页面，Pager 关闭或页面数据被改写后不再有效。
5. 节点类型无效、槽位数量超出上限、值区域越界或深度超限时返回节点错误；Pager 读取失败时返回存储错误。

## 当前 insert 行为

1. 空树首次插入时，Pager 分配一个新页面并初始化为叶子根页。
2. 非空树按内部节点分隔键定位叶子，在叶子中按键升序插入槽位和值。
3. 重复键返回 `DuplicateKey`。叶子页没有足够空间时会尝试按记录数均分到左右叶子，并将分隔键插入父节点。父节点已满时会合并分隔键和子页指针后拆成两个内部节点，再将提升的分隔键递归插入上层；根节点已满时会创建新的内部根节点。若均分后值数据仍放不下，则返回 `NoSpace`。
4. 成功插入会将页面标记为脏页，由 Pager 刷新到磁盘。根页号目前由调用方持有，尚未写入数据库元数据。

删除操作会从叶子移除记录并压紧值数据；节点低于最小占用时使用重平衡流程恢复结构。

## 相邻兄弟页接口

`BPlusTree.siblingPageId(page_id, direction)` 用于取得当前节点在**同一父节点下**的前一个或后一个兄弟页号。方向类型约定为 `SiblingDirection.previous` / `SiblingDirection.next`，返回类型为 `SearchError!?u32`。

- 当前节点是根节点，或目标方向越过同父节点的边界时，返回 `null`。
- 当前节点必须由其父内部节点引用；若父节点不是内部节点，返回 `InvalidNodeType`；若父节点未引用当前页，返回 `CorruptNode`。
- Pager 读取失败返回 `Storage`。该接口只返回页号，不固定或返回页面指针。
- “兄弟”只指同一个父节点下相邻的子页，不承诺跨父节点的全树前驱／后继；叶子全序遍历仍使用叶子链或游标接口。

接口测试位于 `src/storage/btree_neighbor_test.zig` 并已接入集成测试。

## 相邻节点合并

`BPlusTree.mergeSiblings(left_page_id, right_page_id)` 将同父节点下相邻、同类型的两个节点合并到左页，并删除父节点中两者之间的分隔键。叶子节点按键顺序合并记录和值，且左叶子接续到右叶子的后继；内部节点按“左侧槽位、父分隔键、右侧槽位”的顺序合并，并更新合并后所有子节点的父页号。若父节点是空根，根页会收缩到合并后的左页。

若节点不是兄弟、顺序不相邻、类型不同或合并后超过单页容量，接口返回对应错误且不进行合并。直接调用 `mergeSiblings` 不会递归调整父节点；需要递归处理占用时调用 `rebalanceNode`。右节点和被收缩的旧根页会清零，但 Pager 暂不回收或重用这些页号。合并测试位于 `src/storage/btree_merge_test.zig`。

## 相邻兄弟重分配

`BPlusTree.redistributeSiblings(left_page_id, right_page_id)` 在同父节点下重新平衡相邻、同类型的兄弟。叶子节点按记录顺序合并后，在两页都能容纳的切点中选择最接近平分的位置，并把右页首键写回父分隔键；内部节点把父分隔键并入有序序列，再提升中间分隔键、重建两侧节点并更新子页父页号。叶子链连接保持不变。测试位于 `src/storage/btree_redistribute_test.zig`。

## 自动重平衡

`BPlusTree.rebalanceNode(page_id)` 按最大槽位数的一半（本格式为 170）作为非根节点最小占用。节点低于最小占用时先尝试与左右兄弟重分配；重分配后双方仍低于下限时再尝试合并。合并会移除父分隔键，因此算法继续重平衡父节点，直到父节点恢复占用、无法继续调整或根收缩。根节点不受最小占用约束；空内部根会收缩到唯一子节点。删除操作在删除非根叶子记录后调用此流程。

## 删除接口

预期接口为 `BPlusTree.delete(key) DeleteError!bool`：空树或键不存在时返回 `false`；找到并删除记录时返回 `true`。删除叶子记录后，槽位保持有序，剩余值字节会压紧并修正偏移；若右子树的最小键变化，父分隔键同步更新。非根节点低于最小占用时调用 `rebalanceNode`，依次尝试重分配、合并和父节点递归重平衡。删除树中最后一条记录后将根页号置空。

删除测试位于 `src/storage/btree_delete_test.zig` 并接入集成测试。
